FAQ

Pertanyaan umum.

Apakah foto saya publik?

Tidak. Konfigurasi Supabase menggunakan bucket private dan policy untuk membatasi akses.

Apakah admin bisa melihat password user?

Tidak. Password Auth tidak boleh ditampilkan pada dashboard admin.

Apakah admin bisa melihat foto user?

Bisa dibuat melalui jalur admin yang terotorisasi dan tercatat. Jangan memberikan service-role key ke browser.

Apakah kapasitas bisa ditambah?

Ya. Tabel quota sudah tersedia pada struktur database, sedangkan pembayaran dan billing perlu dihubungkan ke backend.

Apakah bisa dipakai dari HP?

Ya, layout dibuat responsive.
